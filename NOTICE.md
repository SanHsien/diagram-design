## Project Scope

This repository ships an agent skill that produces editorial diagrams as self-contained HTML + SVG files, plus Python verifiers for skin, geometry, import, and docs sync. It is a maintenance fork, not a second official product site.

It does not include API keys, generated user diagrams, or unpublished client brand profiles. Do not commit `.env*` files, credentials, or live brand tokens copied from a private site.
